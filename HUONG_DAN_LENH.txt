HƯỚNG DẪN SỬ DỤNG PATCHX
========================

Cách chạy chung:

    python3 patchx <LỆNH> [TÙY CHỌN]

Chọn lệnh theo số thứ tự thật (danh mục khi chạy `python3 pushx`):

    python3 pushx 01                 # intake --help
    python3 pushx 13 app.apk --mode auto  # pipeline app.apk --mode auto

Các số chạy liên tục từ 01 đến 68, đúng thứ tự hiển thị. Tên lệnh có màu
trắng đậm, mô tả có màu xám để dễ phân biệt trong terminal hỗ trợ ANSI.

Lưu ý:
- Tên lệnh và tên tùy chọn phải gõ đúng chữ không dấu.
- Tham số CÂY_APK là thư mục APK đã giải mã bằng apktool.
- Tham số THƯ_MỤC_PATCH là thư mục chứa các file patch .zip/.txt.

Muốn xem trợ giúp riêng từng lệnh:

    python3 patchx <LỆNH> --help

======================================================================
TÀI LIỆU RIÊNG CHO NHÓM BEHAVIOR + FRIDA + GADGET
======================================================================

Nhóm lệnh liên quan đến phân tích hành vi, sinh hook Frida và nhúng
Frida Gadget đã được tách sang file:

    HUONG_DAN_BEHAVIOR_FRIDA.txt

Hướng dẫn riêng cho Frida Gadget:

    HUONG_DAN_GADGET.txt

Các lệnh trong file riêng:

    behavior
    targets
    targets-fused
    discover
    behavior-pipeline
    remote-map
    remote-patch
    remote-observe
    frida
    gadget-pipeline

File đó mô tả chi tiết:
- Công dụng, đầu vào, đầu ra và các tùy chọn của từng lệnh.
- Quy trình cũ chạy Frida thông thường.
- Quy trình mới nhúng Frida Gadget không cần root.
- Cách tạo APK Gadget, kích hoạt, nghe lệnh và gỡ lỗi.
- Cách chọn target theo danh sách như 1,3,5 hoặc all.
- Cách dùng remote-observe điều khiển hành vi từ xa.

======================================================================
DANH SÁCH LỆNH NGUỒN CŨ, CÔNG DỤNG VÀ VÍ DỤ
======================================================================

1. scan
   Công dụng: Quét thư mục patch, in tóm tắt và phát hiện file trùng nội dung.
   Ví dụ:
       python3 patchx scan thu_muc_patch --recursive

2. index
   Công dụng: Tạo index.json và report.md cho thư mục patch.
   Ví dụ:
       python3 patchx index thu_muc_patch -o index_out --recursive

3. dupes
   Công dụng: Phát hiện các patch trùng nội dung theo hash.
   Ví dụ:
       python3 patchx dupes thu_muc_patch

4. manifest
   Công dụng: Tạo MANIFEST.json cho toàn bộ cây thư mục patch.
   Ví dụ:
       python3 patchx manifest thu_muc_patch

5. verify-manifest
   Công dụng: Xác minh thư mục hiện tại so với MANIFEST.json đã có.
   Ví dụ:
       python3 patchx verify-manifest thu_muc_patch --manifest MANIFEST.json

6. report
   Công dụng: Tạo báo cáo HTML cho kho patch.
   Ví dụ:
       python3 patchx report thu_muc_patch -o report.html

7. ci
   Công dụng: Chạy dây chuyền CI: audit -> upgrade -> optimize -> combo -> simulate.
   Ví dụ:
       python3 patchx ci thu_muc_patch -o ci_out

8. golden
   Công dụng: Chạy cổng Golden Build để kiểm tra hai golden test.
   Ví dụ:
       python3 patchx golden -o golden_out --fw

9. validate
   Công dụng: Xác thực cây APK, gồm Smali, XML và DEX.
   Ví dụ:
       python3 patchx validate outputs/apk/apk-trees/app --level NORMAL

10. apk-prepare
    Công dụng: Giải mã APK bằng apktool thành cây thư mục.
    Ví dụ:
        python3 patchx apk-prepare app.apk -o outputs/apk/apk-trees/app

11. audit
    Công dụng: Kiểm tra kiến trúc từng patch và tìm lỗi an toàn.
    Ví dụ:
        python3 patchx audit thu_muc_patch

12. upgrade
    Công dụng: Nâng cấp patch an toàn: metadata, thẻ dòng, gộp trùng.
    Ví dụ:
        python3 patchx upgrade thu_muc_patch -o upgraded

13. optimize
    Công dụng: Gộp patch, loại bỏ phần trùng lặp.
    Ví dụ:
        python3 patchx optimize thu_muc_patch -o optimized

14. apply
    Công dụng: Áp patch lên cây APK.
    Ví dụ:
        python3 patchx apply patch.zip outputs/apk/apk-trees/app --dry-run

15. test
    Công dụng: Chạy bộ kiểm tra nội bộ.
    Ví dụ:
        python3 patchx test

16. dex-budget
    Công dụng: Ước lượng giới hạn DEX refs khi thêm mã.
    Ví dụ:
        python3 patchx dex-budget outputs/apk/apk-trees/app patch.txt

17. preflight
    Công dụng: Kiểm tra trước khi áp patch.
    Ví dụ:
        python3 patchx preflight patch.zip outputs/apk/apk-trees/app

18. fuzz
    Công dụng: Tấn công fuzz/chaos parser và engine.
    Ví dụ:
        python3 patchx fuzz --rounds 100

19. failure
    Công dụng: Quản lý cơ sở dữ liệu Failure Intelligence.
    Ví dụ:
        python3 patchx failure --action record

20. baseline
    Công dụng: Chụp và so sánh baseline performance/metrics.
    Ví dụ:
        python3 patchx baseline --action capture

21. coverage
    Công dụng: Đo độ bao phủ của patch lên APK.
    Ví dụ:
        python3 patchx coverage patch.zip outputs/apk/apk-trees/app

22. suggest
    Công dụng: Tự đề xuất cải tiến cho patch.
    Ví dụ:
        python3 patchx suggest patch.zip outputs/apk/apk-trees/app

23. analyze
    Công dụng: Phân tích ngữ nghĩa cây APK.
    Ví dụ:
        python3 patchx analyze outputs/apk/apk-trees/app

24. model
    Công dụng: Tạo mô hình trung gian app_model.json cho cây APK.
    Ví dụ:
        python3 patchx model outputs/apk/apk-trees/app -o app_model.json

25. semantic-plan
    Công dụng: Đánh giá kế hoạch ngữ nghĩa cho APK.
    Ví dụ:
        python3 patchx semantic-plan plan.json outputs/apk/apk-trees/app

26. acceptance
    Công dụng: Chạy tiêu chí nghiệm thu V2.
    Ví dụ:
        python3 patchx acceptance fixtures

27. knowledge
    Công dụng: Quản lý kho tri thức nghiệm thu.
    Ví dụ:
        python3 patchx knowledge --action query

28. plan-compile
    Công dụng: Tạo transaction nháp từ plan V2.
    Ví dụ:
        python3 patchx plan-compile plan_v2.json outputs/apk/apk-trees/app -o draft.json

29. plan-preflight
    Công dụng: Đánh giá lại draft transaction trên cây mới.
    Ví dụ:
        python3 patchx plan-preflight draft.json outputs/apk/apk-trees/app

30. diff-apk
    Công dụng: Sinh patch từ sự khác biệt giữa hai APK hoặc hai cây APK.
    Ví dụ:
        python3 patchx diff-apk apk_goc.apk apk_da_sua.apk -o diff.patch

31. suggest-apk
    Công dụng: Gợi ý patch theo APK thật.
    Ví dụ:
        python3 patchx suggest-apk outputs/apk/apk-trees/app thu_muc_patch

32. suggest-llm
    Công dụng: Gợi ý patch theo ý định người dùng.
    Ví dụ:
        python3 patchx suggest-llm thu_muc_patch "bo kiem tra root"

33. roadmap
    Công dụng: Sinh lộ trình thực thi patch.
    Ví dụ:
        python3 patchx roadmap thu_muc_patch outputs/apk/apk-trees/app

34. simulate
    Công dụng: Mô phỏng áp patch lên cây APK.
    Ví dụ:
        python3 patchx simulate thu_muc_patch --apk outputs/apk/apk-trees/app

35. selfcheck
    Công dụng: Tự kiểm tra module và kho patch.
    Ví dụ:
        python3 patchx selfcheck .

36. combo
    Công dụng: Tạo các bộ gộp patch.
    Ví dụ:
        python3 patchx combo thu_muc_patch --auto

37. ui
    Công dụng: Mở giao diện dòng lệnh TUI.
    Ví dụ:
        python3 patchx ui

38. stats
    Công dụng: Thống kê tổng quan kho patch.
    Ví dụ:
        python3 patchx stats thu_muc_patch

39. clean
    Công dụng: Dọn dẹp tệp và thư mục tạm.
    Ví dụ:
        python3 patchx clean thu_muc_goc

======================================================================
GHI CHÚ
======================================================================

- Muốn phân tích hành vi, sinh hook Frida hoặc nhúng Gadget, xem:
  HUONG_DAN_BEHAVIOR_FRIDA.txt
- Muốn hướng dẫn chi tiết riêng Frida Gadget, xem:
  HUONG_DAN_GADGET.txt
- Muốn build APK, máy cần có apktool.
- Muốn cài APK lên thiết bị, cần apksigner/zipalign hoặc dùng adb.
- Các tên lệnh và tùy chọn trong tài liệu phải gõ đúng chữ không dấu.

- `patchx smart-patch CÂY [--apply]` — lập kế hoạch/áp patch smali
  thông minh: tái dùng detector behavior (kể cả nhánh obfuscated-*),
  chống R8/D8; `--apply` ghi đè smali (backup tự động).
- `patchx pairip-bypass CÂY [--apply]` — vô hiệu hóa PairIP (license
  check, `com.pairip.*`) trên cây APK: bỏ gọi `checkLicense` ở
  `Application.attachBaseContext` + `LicenseContentProvider.onCreate`,
  nop 4 method `LicenseClient` (`checkLicense`/`stopTrial`/`handleTrialEnd`/
  `initializeLicenseCheck`), `LicenseActivity.onStart` tự `finish`;
  `--apply` ghi đè smali (backup tự động, idempotent); báo cáo tại
  `outputs/behavior/pairip_bypass/`.


======================================================================
TỐI ƯU MODDER HUB — FAST PATH
======================================================================

dex-patch
   Patch chuỗi UTF-8 trực tiếp trong classes*.dex, tự cập nhật SHA-1/Adler32
   và tạo backup. Mặc định không dùng apktool:
       python3 patchx dex-patch classes.dex --replace OLD=NEW
   Kiểm tra trước, không ghi:
       python3 patchx dex-patch classes.dex --dry-run --replace OLD=NEW

apk-repack-fast
   Repack chỉ các entry thay đổi của APK, giữ lại entry khác và không tự ký:
       python3 patchx apk-repack-fast app.apk -o app_fast.apk \
           --update classes.dex=/tmp/classes.dex
   Luôn dùng APK đầu ra mới; bước ký/verify thực hiện riêng sau đó.

axml-patch
   Inspect hoặc thay chuỗi nhị phân AXML/ARSC có cùng/nhỏ hơn độ dài; luôn có backup:
       python3 patchx axml-patch AndroidManifest.xml OLD NEW --dry-run
   Báo cáo bảo mật Manifest (networkSecurityConfig, cleartext, debuggable, permissions):
       python3 patchx axml-patch AndroidManifest.xml --inspect-security
   Vô hiệu hóa Network Security Config (bỏ qua SSL Pinning tầng XML):
       python3 patchx axml-patch AndroidManifest.xml --bypass-nsc
   Thay đổi permission in-place:
       python3 patchx axml-patch AndroidManifest.xml --replace-perm OLD_PERM=NEW_PERM

signature-cert
   Trích DER cert v1 gốc, SHA-256 và context PATCHX_RSA_DATA; không ký APK:
       python3 patchx signature-cert app.apk -o outputs/signature_context.json

macro-list
   Liệt kê Smali macro và kiểm tra số register dự kiến:
       python3 patchx macro-list --registers 2

fast-patch
   Quy trình 1-Click vá DEX, AndroidManifest.xml, resources.arsc in-place và repack
   siêu tốc trong < 0.5 giây, tự động gỡ chữ ký cũ để chuẩn bị ký mới:
       python3 patchx fast-patch app.apk -o app_patched.apk \
           --dex-str "https://api.old.com"="https://api.new.com" \
           --dex-hex 12000f00=12100f00 \
           --axml "com.old.pkg"="com.new.pkg" \
           --arsc "OldAppName"="NewAppName"

arsc-patch
   Phân tích và thay thế chuỗi in-place trong String Pool của resources.arsc:
       python3 patchx arsc-patch resources.arsc --inspect
       python3 patchx arsc-patch resources.arsc "OldStr" "NewStr"
       python3 patchx arsc-patch resources.arsc --replace "OldStr=NewStr" --backup backup.arsc

native-sig-bypass
   Quy trình 1-Click tự động quét và bypass SHA-256 cert hash trong các thư viện native .so:
       python3 patchx native-sig-bypass app.apk --orig-apk orig.apk -o out.apk
       python3 patchx native-sig-bypass app.apk --dry-run

apk-patch --fast (Toolkit Pipeline)
   Tích hợp Fast-Path vào orchestrator của toolkit, tự động ký số debug:
       python3 patchx_toolkit.py apk-patch app.apk --fast \
           --dex-str "old_val=new_val" --axml "old_pkg=new_pkg" --arsc "OldApp=NewApp"

apk-build (Toolkit Pipeline) — có bước 1.5 chặn VerifyError
   Build nhanh: xác thực hình dạng smali → CỔNG NGỮ NGHĨA (bước 1.5) → resource →
   apktool b → zipalign → ký → verify. Bước 1.5 chặn build khi có lỗi "đọc thanh ghi
   chưa gán trên một đường đi nào đó" (nguyên nhân thật của VerifyError khi mở app):
       python3 patchx_toolkit.py apk-build outputs/apk/apk-trees/2_src
       python3 patchx_toolkit.py apk-build <cây> --cong-ngu-nghia-all   # quét cả tệp chưa vá
       python3 patchx_toolkit.py apk-build <cây> --bo-cong-ngu-nghia    # bỏ qua có chủ ý
   Báo cáo: outputs/apk/apk-build/apk_build_report.json (mục "cong_ngu_nghia").
   Cổng này nay cũng được móc vào: apk-patch (bước 4.5), apk-debug (không cần build),
   apk-full (bước 4.5). Cả 4 lệnh đều nhận --bo-cong-ngu-nghia / --cong-ngu-nghia-all.

kiem-tra-verify (cổng ngữ nghĩa smali, chạy riêng)
   Kiểm NGỮ NGHĨA smali: N1 = đọc thanh ghi chưa gán (LỖI, chặn build);
   N2 = vùng vá ghi đè thanh ghi mà đoạn ngoài vùng vá còn đọc (CẢNH BÁO).
       python3 tools/kiem_tra_verify.py --tu-kiem                 # tự kiểm 3 chiều (dương/âm/chê lỗi)
       python3 tools/kiem_tra_verify.py --tree Apks/2             # chỉ tệp có dấu # PATCHX (~0,5 giây)
       python3 tools/kiem_tra_verify.py --tree Apks/2 --all       # cả cây (~38 giây, 12.196 tệp)
       python3 tools/kiem_tra_verify.py --file <tệp.smali> --json  # 1 tệp, xuất JSON
       python3 tools/kiem_tra_verify.py --do-lech <tệp.smali> --ham startTranslation --pc 0x8E
   Lỗi in kèm độ lệch code-unit (pc) để đối chiếu thẳng với mã máy ảo ART và đường đi thiếu gán.
   In kèm thời gian tách riêng (tìm tệp / phân tích / tổng). Tìm tệp dùng `grep -rl` khi có,
   có đối chứng cho thấy hai đường cho cùng danh sách tệp (không bỏ sót tệp đã vá).

kiem-cong-cu (cổng tự kiểm công cụ + sổ "tin dùng")
   Chống đúng loại sai 2026-09-20: bàn giao một công cụ chưa tự chứng minh rồi đem tin dùng.
   Quy tắc: công cụ chỉ được quyền CHẶN build khi sổ "tin dùng" cho phép; chưa có sổ thì
   nó phải tự kiểm đạt ngay tại chỗ; tự kiểm hỏng thì chỉ được CHẠY BÓNG (cảnh báo, không chặn).
       python3 tools/kiem_cong_cu.py                       # quét + in bảng trạng thái
       python3 tools/kiem_cong_cu.py --quet --ghi-so       # quét, chạy tự kiểm, ghi sổ
       python3 tools/kiem_cong_cu.py --dat-tin-dung <tệp> --nguon User --ly-do "..."
       python3 tools/kiem_cong_cu.py --dat-canh-bao <tệp> --ly-do "..."   # hạ xuống chạy bóng
       python3 tools/kiem_cong_cu.py --json
   Sổ: outputs/cong_cu/trang_thai.json (mã băm từng công cụ; sửa tệp ⇒ tự hạ về chưa_kiem).
   CHỈ User được nâng lên "tin_dung" (lệnh sẽ từ chối nếu --nguon khác User).
   Thoát mã 1 nếu có công cụ đang CHẶN mà chưa tự kiểm đạt.

doc-dex / song-thanh-ghi (công cụ đọc, KHÔNG dùng làm cổng chặn)
       python3 tools/doc_dex.py <tệp.dex> <class> <method>     # kiểm chứng bản vá nằm trong APK
       python3 tools/song_thanh_ghi.py <tệp.smali> <hàm> <dòng> ...  # đo thanh ghi còn sống

smart-combo
   Tự động sinh combo patch tối ưu từ Active Learning (AST Smali + combos_success.json):
       python3 patchx smart-combo outputs/apk/apk-trees/a_src --intent bypass-license -o combos/
       python3 patchx smart-combo outputs/apk/apk-trees/a_src --max-patches 3 --apply

intake
   Tiếp nhận artifact Android (APK, APKS, XAPK, AAB) và tạo evidence report chỉ đọc:
       python3 patchx intake app.apk -o outputs/intake
       python3 patchx intake app.apks --no-tool-probe

capabilities
   Ghi snapshot kiểm tra công cụ hiện có trong môi trường (Java, JADX, aapt2, apksigner...):
       python3 patchx capabilities -o outputs/intake

pipeline
   Khởi chạy Unified Pipeline tích hợp (auto, intake, fast, behavior, native, combo):
       python3 patchx pipeline app.apk --mode auto
       python3 patchx pipeline app.apk --mode fast --dex-str "old=new" --axml "old=new"
       python3 patchx pipeline app.apk --mode intake -o outputs/pipeline
       python3 patchx pipeline app.apk --mode native

discover (alias: universal-discovery, deep-scan)
   Phân tích thông minh toàn diện: Quét mọi tệp nhạy cảm (assets/cert/db/raw) & Khai phá từ điển động (Dynamic Lexicon) không giới hạn từ khóa:
       python3 patchx discover app.apk
       python3 patchx discover outputs/apk/apk-trees/a_src -o outputs/discovery

subtitle-tts (alias: subtitle-reader, realtime-subtitles)
   Động cơ điều phối & chẩn đoán đọc phụ đề thời gian thực bằng giọng nói TTS (Sliding Window Dedup, Dynamic Speed Scaling):
       python3 patchx subtitle-tts
       python3 patchx subtitle-tts outputs/apk/apk-trees/a_src

auto-refresh (alias: auto-session, auto-reset-translation)
   Tự động reset và bật lại dịch phụ đề + chia sẻ toàn màn hình sau mỗi 2 phút 40 giây (160s) chống ngắt kết nối:
       python3 patchx auto-refresh
       python3 patchx auto-refresh --interval 160 --package com.sota.aitranslatex
       python3 patchx auto-refresh --device 100.64.170.99:5555 --root
       python3 patchx auto-refresh --once --no-tts
       ./tools/auto_reset.sh





dag
   Xem và chạy các quy trình theo DAG Dependency Engine + Pipeline Registry:
       python3 patchx dag --list
       python3 patchx dag --inspect auto
       python3 patchx dag --mermaid auto
       python3 patchx dag --run fast app.apk

packet
   Bộ công cụ an ninh mạng gói tin tích hợp trong Toolkit:
       python3 patchx packet guard --demo
       python3 patchx packet guard --attack-tamper
       python3 patchx packet forge demo
       python3 patchx packet forge inject --host 127.0.0.1 --port 9000 --text "PING"
       python3 patchx packet arena
       python3 patchx packet middleware --host 127.0.0.1 --port 9999
       python3 -m patchx_core.packet_security forge fuzz --text "SAMPLE" --rate 0.05

neon-bench
   Đo tốc độ GB/s THẬT của đường quét NEON ARM64 so với Python thuần (biên dịch clang -O3 tại chỗ, tự rơi về Python nếu thất bại):
       python3 patchx neon-bench --size-mb 64 --iterations 3
       python3 patchx neon-bench -o outputs/behavior/neon_bench.json

smart-scan (nâng cấp NEON)
   Đường quét chuỗi mặc định tự dùng kernel NEON native nếu biên dịch được; điều khiển bằng:
       python3 patchx smart-scan lib.so --native          # bắt buộc NEON
       python3 patchx smart-scan lib.so --no-native       # Python thuần
       python3 patchx smart-scan --benchmark 64           # đo NEON vs Python rồi thoát
   Lệnh start-scan cũng nhận --native/--no-native và in số lib chạy từng động cơ.

unflatten
   Gỡ phẳng luồng mã bị làm rối kiểu switch-case (R8/DexGuard) và cắt tỉa khối chết; mặc định chỉ phân tích:
       python3 patchx unflatten Cay.smali
       python3 patchx unflatten outputs/apk/apk-trees/app --apply --limit 200
       python3 patchx unflatten Cay.smali --apply -o outputs/unflatten_report.json
   Khi --apply, mỗi tệp được sao lưu .bak vào outputs/backup/unflatten/ trước khi ghi.

autopilot (nâng cấp toàn trình qua DAG)
   Tự hành 1-chạm: tiếp nhận -> giải mã(tùy chọn) -> vá toàn vẹn 4 tầng -> cổng bảo vệ
   -> mạng NSC/SSL -> mã máy .so -> gỡ phẳng -> kiểm chứng Micro-DEX -> đóng gói & ký số:
       python3 patchx autopilot app.apk --network --native-patch --decompile
       python3 patchx autopilot cay_smali --network --native-patch --unflatten --package
       python3 patchx autopilot app.apk --dry-run                       # chỉ phân tích, không ghi
       python3 patchx autopilot app.apk --no-package                    # bỏ bước đóng gói
       python3 patchx dag --run autopilot app.apk                       # chạy qua sổ bộ DAG

auto-gate
   Tự động can thiệp các cổng an ninh bằng bộ sửa mã trung gian và kiểm chứng Micro-DEX:
       python3 patchx auto-gate outputs/apk/apk-trees/app

network-bypass
   Đột phá tầng mạng: mở khóa Network Security Config, cho phép chứng chỉ người dùng,
   bật lưu lượng thô và sinh kịch bản vô hiệu hóa SSL Pinning đa tầng:
       python3 patchx network-bypass app.apk
       python3 patchx network-bypass outputs/apk/apk-trees/app

native-auto-patch
   Đột phá tầng thư viện máy: quét chốt chặn Anti-Root/Anti-Debug/endpoint và đột biến
   nhị phân zero-drift (không lệch kích thước), kèm sinh kịch bản Frida:
       python3 patchx native-auto-patch --so-dir lib
       python3 patchx native-auto-patch --apk app.apk

precompile
   Tiền biên dịch toàn bộ mã nguồn hệ thống sang bytecode tối ưu song song trên 8 nhân CPU:
       python3 patchx precompile
       python3 patchx precompile --workers 8 --optimize 1

integrity-gate
   Một cổng kiểm tra toàn vẹn xuyên tầng G1..G5 (vân tay/neo -> cấu trúc ->
   ngữ nghĩa Micro-DEX -> hành vi -> chống báo đạt giả) cho smali/DEX/ELF/APK/cây:
       python3 patchx integrity-gate Cay.smali
       python3 patchx integrity-gate classes.dex
       python3 patchx integrity-gate libnative.so
       python3 patchx integrity-gate app.apk -o outputs/gate_report.json

ast-dsl
   Vá ngữ nghĩa bằng ngôn ngữ quy tắc trên cây AST Smali (tìm mẫu -> ràng buộc
   thanh ghi/kiểu -> biến đổi AST -> in lại smali hợp lệ), miễn nhiễm đổi tên:
       python3 patchx ast-dsl Cay.smali --rules rules.json                # chỉ phân tích
       python3 patchx ast-dsl Cay.smali --rules rules.json --apply        # ghi thật (tự .bak)
       python3 patchx ast-dsl cay_smali --rules rules.json -o outputs/ast_dsl.json
   Quy tắc JSON ví dụ:
       {"ten":"mo-khoa","phuong_thuc":"check.*","opcode":"if-eqz",
        "toan_hang":":cond_fail","hanh_dong":"dao-nhanh"}
       {"ten":"tra-true","phuong_thuc":"isPremium","hanh_dong":"ep-tra-ve","gia_tri":true}

dex-method
   Trình sửa DEX ở mức phương thức: xem bản đồ tên->lệnh hoặc vá opcode cùng độ dài (tự tính lại chữ ký):
       python3 patchx dex-method classes.dex --map
       python3 patchx dex-method classes.dex --method "isVip" --swap "1200=1201" --apply
       python3 patchx dex-method classes.dex -o outputs/dex_method_report.json
